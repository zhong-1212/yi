# 形法要点（xingfa）

风水先看**形**，后算**卦**。看得见的形不合格，再好的卦也没用。现代住宅尤其如此：公寓的"形"就是采光、通风、噪音、视线、动线。

## 一、判断三原则（先背这三条）

1. **看见的 > 算出的**：窗正对直路、楼间距窄、无采光——这些先处理，卦位排后。
2. **能改的 > 不能改的**：能挪床、换帘、加收纳的先做；改墙、改门、换房先别想。
3. **物理问题先归物理**：潮湿、霉味、油烟、噪音、眩光、一氧化碳——这些是健康与安全问题，找物业/维修/专业，不靠摆件。

## 二、外局六看（站在门口/窗前，一分钟能看完）

| 看 | 要看的形 | 合格/不合格 |
|---|---|---|
| 明堂 | 门前、窗前有无缓冲空间 | 开阔、能停住气 → 合格；一开门就是马路/电梯井 → 不合格 |
| 靠山 | 窗外背后有无实体 | 楼栋、实墙为靠；全空、临崖、临大路 → 无靠 |
| 水路 | 道路、河流、车流走向 | 环抱（弯内侧）为顺；反弓（弯外侧）为逆 |
| 冲射 | 路冲、巷冲、楼缝（天斩）、尖角、烟囱、水塔正对 | 有直冲、正对 → 记一笔 |
| 高低 | 前后楼高差、地势 | 前低后高为顺；前高压顶、四周楼过高 → 压 |
| 近邻 | 垃圾站、变电箱、车库出入口、公厕、高架、施工地 | 近邻带来的噪音/气味/振动/安全更值得处理 |

> 现代补充：**采光时长**（冬至日日照）、**通风路径**（是否能对流通风）、**噪音级**这三项，比"煞名"实用得多。

## 三、内局八看

| 位 | 要点 |
|---|---|
| 门 | 门正对电梯、楼梯、厕所、镜、灶 → 记；门的开合是否顺畅、是否挡消防通道 |
| 玄关 | 有无过渡（换鞋、挂衣），是否一进门直视到底（穿堂） |
| 客厅 | 采光与动线；沙发是否背门、是否横梁压顶 |
| 卧室 | 床头有靠、不对门、不背窗、不压梁、镜不对床；卧室门不对厕门 |
| 厨房 | 灶不对水槽（传统"水火相冲"）、灶不正对门、油烟排出顺畅、燃气安全 |
| 卫浴 | 厕所门不对大门/卧室门/餐桌；有窗或排风；干湿分离；防水与霉变 |
| 书房/工作区 | 座位背后有靠、不正对门、桌面不对锐角、灯光不刺眼 |
| 动线 | 走廊是否过长直冲、门是否对门、开关插座与家具是否打架 |

## 四、常见误判（用户最容易对号入座的地方）

- **把噪音当"煞"**：先把窗、墙体、耳塞解决，再谈方位。
- **把西晒当"凶"**：西晒是热工问题，遮阳帘/隔热膜解决。
- **把缺角当"大祸"**：缺角影响的是空间使用与家具摆放，传统才谈宫位。
- **把"楼间距窄"当"天斩"**：天斩是两楼夹出的**窄缝直冲**，不是"楼近"。
- **把"门前有树"当"挡财"**：先看树是否挡光、挡视线、拱根（安全），不是判吉凶。
- **把"厕所门对床"当"重病"**：传统谈的是气味、湿气与隐私，现代直接做干湿分离＋排风。

## 五、改法分级（按成本从低到高）

1. **零成本**：换位置、开合门、收杂物、调灯、拉帘。
2. **低成本**：门帘、地垫、屏风、半高柜、绿植、纱帘、收纳箱。
3. **中成本**：换床、换书桌、加装排风、加装遮阳、换灯具。
4. **高成本/不建议**：拆墙、改门洞、改承重、改燃气电路 → **必须找专业与物业，且与本技能无关**。

## 六、租房与买房

- **租房**：只做 1、2 级调整，别为房子花大钱；重大缺陷（渗水、霉变、无消防通道）先跟房东谈。
- **买房/装修**：形法在**看房阶段**价值最大（采光/通风/噪音/朝向/楼距），签完再谈理气。

## 七、报告口径

- 先说"形"（可验证：采光、通风、噪音、动线），再说"卦"（传统取用）。
- 每条问题给**一个可执行动作**，只给一条，别列二十条。
- 永远补一句：**这些是居住体验的调整，不是转运承诺**。
