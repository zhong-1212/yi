# 八宅与命卦（bazhai）

本派只看两件事：**宅卦**（房子朝哪）与**命卦**（人属哪一卦），然后按「大游年」把八方分成四吉四凶。

## 一、东西四宅 / 东西四命

| 组 | 卦 | 说明 |
|---|---|---|
| 东四 | 坎、震、巽、离 | 东四宅宜东四命人，东四命人宜居东四宅 |
| 西四 | 乾、坤、艮、兑 | 同上，西四配西四 |

> 现代公寓多不能选朝向，这条只作**取用参考**（睡哪间、书桌朝哪、床头朝哪），不作"必须搬家"的依据。

## 二、大游年歌（八方吉凶）

自伏位（坐山卦）起，按后天八卦**顺时针**布八方：

| 伏位卦 | 八方次序（顺时针） |
|---|---|
| 乾 | 伏位 六煞 天医 五鬼 祸害 绝命 延年 生气 |
| 坎 | 伏位 五鬼 天医 生气 延年 绝命 祸害 六煞 |
| 艮 | 伏位 六煞 绝命 祸害 生气 延年 天医 五鬼 |
| 震 | 伏位 延年 生气 祸害 绝命 五鬼 天医 六煞 |
| 巽 | 伏位 天医 五鬼 六煞 祸害 生气 绝命 延年 |
| 离 | 伏位 六煞 五鬼 绝命 延年 祸害 生气 天医 |
| 坤 | 伏位 天医 延年 绝命 生气 祸害 五鬼 六煞 |
| 兑 | 伏位 生气 祸害 延年 绝命 六煞 五鬼 天医 |

口诀：**乾六天五祸绝延生**、坎五天生延绝祸六、艮六绝祸生延天五、震延生祸绝五天六、
巽天五六祸生绝延、离六五绝延祸生天、坤天延绝生祸五六、兑生祸延绝六五天。

- 四吉：**伏位**（安稳）、**生气**（生机）、**延年**（和合）、**天医**（调养）
- 四凶：**绝命**（耗散）、**五鬼**（急变口舌）、**六煞**（牵缠是非）、**祸害**（小损口舌）

游年两两成对（乾↔兑生气、乾↔坤延年、乾↔艮天医、乾↔离绝命…），脚本自检会验证这个互反性——
它同时是"表没抄错"的证明。

## 三、取用原则（重要，别用反了）

| 位置 | 取用 |
|---|---|
| 大门、玄关 | 吉方可取（生气、延年优先） |
| 床头、书桌、常坐位 | 吉方（生气、天医、伏位），**忌**五鬼、绝命 |
| 灶（明火） | 传统取吉方或"坐凶向吉"，现代更看**排烟与安全** |
| 凶方怎么办 | **宜静不宜久居**：储物、过道、卫浴、次要功能间 |
| 卧室 | 优先看**床头有靠、不对门、不背窗**（形法优先），再谈卦位 |

**「凶」= 宜静不宜久居，不是灾祸。** 任何把凶方说成"出事""破财""血光"的，都不是本技能的用法。

## 四、命卦

- 男：(100 − 出生年后两位) mod 9，余 0 作 9，余 5 寄坤（2）
- 女：(出生年后两位 − 4) mod 9，余 0 作 9，余 5 寄艮（8）
- 以**立春**为年界：立春前出生按上一年。脚本不查节气，需调用方确认。
- 命卦八方吉凶：把命卦当"伏位"套大游年表（脚本 `--minggua` 直接给）。

用法：床、书桌、常坐位的朝向参考；**同宅不同命**时以主要居住者的命卦为主，不必全家一致。

## 五、口径边界（别混派）

- 本技能只排**八宅游年**，**不排玄空山向飞星**（顺逆口径多、各家有出入，算错比不排更糟）。
- 需要玄空飞星盘、罗盘分金、择日、阴宅勘测 → 明确告知需要专业师傅或专业软件，本技能不硬凑。
- 形法（看得见的形）与理气（算出来的卦）冲突时，**以形法为先**，见 xingfa.md。
