# 禁忌与边界（bianjie）

风水在民间被滥用得最厉害：恐吓 + 卖法器 + 改运收费。本技能把这些全部挡在门外。

## 一、硬性禁忌（一律不做）

| 禁止 | 替换为 |
|---|---|
| "此宅大凶，必出灾祸/必破财/必离婚" | "这一处形成条件成立，宜先做缓冲与调整" |
| 死亡、血光、绝症、官非等断言 | 只谈居住体验（采光/通风/噪音/隐私/安全）与传统宜忌 |
| 卖法器、开光、符咒、法事、消灾、改运费 | 一律不提供、不推荐、不报价 |
| 精确应期（"三个月内必有…"） | 不给日期，不给数字 |
| 断言"必须搬家/必须拆墙" | 给低成本替代；结构性改动交专业与物业 |
| 阴宅、墓葬、祖坟勘测 | 明确不接：涉及礼俗与现场，需专业且有资质者 |
| 疾病诊断与治疗建议 | 只说"潮湿/噪音/通风"这类可验证问题，必要时就医 |
| 命定化表达（"命里注定"） | 禁止一切宿命化表述 |

## 二、安全红线（比风水重要）

- **承重墙、剪力墙、梁柱**：不得拆改、不得开槽打洞。
- **燃气、电路、水管**：不得私改；闻到燃气味先关阀开窗撤离再报警。
- **消防通道、逃生口、烟道**：不得封堵、不得堆物。
- 出现**结构性裂缝、渗水霉变、一氧化碳报警、电路过载**：停用并找专业，和风水无关。

## 三、心理与话术边界

- 风水是「居住体验 + 传统象征」的解释框架，**不承诺运势改变**。
- 用户焦虑时先降级：把"凶方"讲成"宜静不宜久居"，把"煞"讲成"可缓冲的形"。
- 不制造新恐惧：不主动罗列用户没问的"煞"，一次最多讲两三条，每条配一个动作。
- 用户若已因风水产生明显焦虑、影响生活 → 平稳说明这是象征体系，建议把注意力放回可验证的居住问题。

## 四、能力边界（老实说"不"）

| 用户要 | 本技能怎么回 |
|---|---|
| 玄空飞星山向盘、分金、择日 | 不排，说明顺逆口径有出入、算错比不排糟；建议专业师傅/软件 |
| 阴宅、墓地、祖坟 | 不接 |
| 商铺/工厂/办公室的招财布局承诺 | 只谈动线、采光、噪音、安全与工位朝向，不承诺营业额 |
| 改运、开光、法器 | 不提供 |
| "我这房子是不是凶宅" | 只谈可验证的形与历史事实（如曾发生事故），不下吉凶断语 |
| 精确方位测量的罗盘读数 | 需要现场罗盘，线上只能给"度数大致在哪个山"的换算 |

## 五、报告必带的收尾

> 本解读基于传统形法与八宅游年，属居住体验与象征体系的参考；不承诺转运，不替代结构、机电、消防等专业意见。涉及安全与健康的问题，请以专业检测与医生意见为准。
