## 二、体用法

- 动爻所在经卦为**用卦**，另一经卦为**体卦**；体为自己/事主，用为对方/所问之事/外境。
- 生克五断（以体为中心）：
  - **用生体**：得外力、资助、贵人——吉倾向
  - **体生用**：付出、泄气、耗神——先劳后论
  - **用克体**：阻力、压制、被动——宜守不宜攻，须给出化解路径（时间/方位/做法）
  - **体克用**：可掌控但耗力——谋事可为，节奏自定
  - **体用比和**：同五行，顺遂之基
- 互卦为事之中情（过程），变卦为事之终局（结果）；参看互/变二卦上下经卦对体的生克，定过程与结局的走向。
- 卦气旺衰辅助：春木旺、夏火旺、秋金旺、冬水旺、四季月（辰戌丑未）土旺；体卦得时则抗克力增。

## 三、断语方向速查（八类事）

| 问事 | 先看 | 常用取象方向 |
|------|------|---------------|
| 谋划/事业 | 体用生克+官贵类卦（乾震） | 乾主领导/官方，震主动工开创，艮止于边界 |
| 求财 | 财象卦（兑巽坤）+用生体否 | 兑为口舌交易，巽为市利三倍，坤为积储 |
| 感情婚姻 | 咸恒睽革归妹等匹配 | 兑少女/震长男互动，睽为乖隔主先难后合或貌合神离 |
| 出行迁移 | 乾坎震离动象 | 坎险在路，震行勿忧，遇艮宜止期再动 |
| 文书学业 | 离巽+科名象 | 离为文明，巽为风传消息 |
| 健康 | 体卦部位+坎离既济未济 | 仅作"作息/体检提示"口径，禁疾病预言 |
| 人际纠纷 | 讼履睽蹇解 | 讼防口舌见官，解主消散缓和 |
| 时机选择 | 动爻与变卦终局 | 复姤观消息盈虚，遁宜退让，大壮勿过 |

以上为方向性参考，具体必须回到本次卦象（本互变三卦+经文原文）陈述依据，禁止脱离盘面套话。
