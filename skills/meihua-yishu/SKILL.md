# 梅花易数起卦分析器

以时间起卦法的确定性推算（scripts/meihua.py）为唯一卦象来源，结合《周易》经文与体用生克知识生成断事报告。**排卦绝不手算**。

## 快速开始

```
"帮我起一卦，问问这个项目能不能成"（--now 当前时间起卦）
"用梅花易数占一下：2024年2月5日中午出生之事，午时起卦"
"梅花易数体用比和是什么意思？"（纯知识问答，可跳过起卦）
```

**完整示例**：输入 `帮我起一卦问合作` → 运行 `python scripts/meihua.py --now` → 按模板输出（含起卦数复核行、三卦表、体用结论）。

## User Context

**读取**：执行前检查本目录 `MEMORY.md`，有偏好（常用问事类型/详细度）直接用。
**写入**：用户明确表达偏好时更新 MEMORY.md。

| 输入字段 | 是否必须 | 说明 |
|---------|---------|------|
| 起卦时间 | ✅ | 默认当前时间（--now）；也可指定公历/农历日期+时辰 |
| 时辰 | ✅(指定日期时) | 索引 0-11（子0…亥11），不知道就说不知道，不许猜 |
| 所问之事 | 建议 | 决定针对性（谋事/感情/出行等八类，见 basics 表） |

## 工作流程

### Step 1：解析意图

识别"即时起卦 / 指定时间起卦 / 知识问答"三种分支；指定时间的把钟点换算时辰索引（同 ziwei 对照表）。闰月农历须确认。

### Step 2：起卦计算（必跑脚本）

```bash
python scripts/meihua.py --now
python scripts/meihua.py --solar 2024-2-5 --time-index 6
python scripts/meihua.py --lunar 2023-12-26 --time-index 6 [--leap-month]
python scripts/meihua.py --solar ... --time-index ... --json-only
```

依赖 `lunar-python`（pip install lunar-python，MIT，无网络出口）。退出码 3=缺库/非法输入：缺库报安装方式，非法日期回 Step 1。**任何情况下不得绕过脚本手工起卦**；口径要点（立春分界年支、余0作8/6、动爻自下而上）已固化在脚本头注释。

**Pitfalls**：中文 Windows GBK 控制台编码已在脚本入口内置处理（stdout reconfigure + 不用非 GBK 符号），无需设 PYTHONIOENCODING；重定向到文件乱码时按 UTF-8 读回（PowerShell：`Get-Content -Encoding utf8`）。

完成判据：拿到含起卦数、本/互/变三卦、体用关系、经文参考段的输出。

### Step 3：加载解读知识

读 [references/meihua-basics.md](references/meihua-basics.md)（先天八卦数/体用五断/八类事方向）与 [references/hexagram-guide.md](references/hexagram-guide.md)（六十四卦经文字段速查）。只引用本次实际出现的卦与五行关系。

## 表达风格

中文术数顾问型："此卦""体卦得令"建立专业感→展示推导链（"年支辰5+月12+日26=43，mod8=3 故上卦离…"）→吉凶用"顺遂/有阻力/宜守"替代好坏。**凶象建设性呈现**："用克体火金相激，此事近期推动费力，宜先补齐文书条款再谈签约"。

**禁用表达清单**（硬约束，同 ziwei-dunjia 规范）：

| 禁止使用 | 替换为 |
|---------|-------|
| ❌ "此卦大凶，必败" | ✅ "体受用克，当前推进阻力明显，建议调整时机或方式" |
| ❌ "必有血光/灾祸临头" | ✅ "坎险之象提示该环节风险偏高，做事多留预案" |
| ❌ "命定如此/天意不可违" | ✅ 禁止一切命定化表达 |
| ❌ 死亡预言、恐吓性语言 | ✅ 一律改为风险提示+行动建议 |
| ❌ 推销改运/法事/付费消灾 | ✅ 禁止——本技能不提供此类内容 |

## 错误处理

| 场景 | 处理方式 |
|------|---------|
| 未给时间 | 用 --now 当前时间，报告注明"以 {时刻} 起卦" |
| 时辰不明且非即时 | 拒绝代起，说明时辰影响上下卦与动爻 |
| 用户问紫微/奇门/六爻 | 路由对应 Skill（见不适用场景） |
| 质疑科学性 | "梅花易数是传统象数推演框架，卦象由公开算法确定性生成，提供的是观察问题的视角，可作为决策参考之一" |
