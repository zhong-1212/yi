# 紫微斗数解读速查（interpretation-guide）

来源标注：主星/辅星性质与格局条目综合自《紫微斗数全书》（陈希夷传本，公有领域）、iztro/x-iztro 官方文档（https://github.com/SylarLong/iztro 、https://ziwei.x-haose.com/en/docs/python）及 Renhuai123/ziwei-doushu 开源知识库的公开整理（MIT/CC BY 4.0）。亮度体系采用七档：庙旺得利平不陷。仅当盘面出现对应星曜时才引用本文件条目。

## 一、十四主星

### 北斗系

| 星 | 五行/属性 | 核心意象 | 庙旺表现 | 落陷/煞并时留意 |
|----|----------|---------|---------|----------------|
| 紫微 | 己土·阴·帝王星 | 尊贵、统御、格局 | 领导气度、能容众星解厄 | 孤高自负；无左辅右弼为"在野之君"，宜借团队补位 |
| 天机 | 乙木·阴·善星 | 谋略、变动、机敏 | 策划周详、技术专长 | 思虑过度、决策摇摆；加煞易神经紧张 |
| 太阳 | 丙火·阳·贵星 | 博爱、发散、名声 | 普照利他、事业外显 | 陷地心有余力不足；劳碌、付出感重 |
| 武曲 | 辛金·阴·财星 | 刚毅、执行、财帛 | 果断生财、军警财经皆宜 | 孤克倔强；与煞同宫防因财起争 |
| 天同 | 壬水·阳·福星 | 温和、知足、协调 | 遇难呈祥、人缘舒适 | 陷地惰性、情绪化；怕纵欲安逸荒废 |
| 廉贞 | 丁火·阴·囚星/桃花 | 交际、才艺、执念 | 雄断有魅力、公关长才 | 陷地+煞称"廉贞煞忌"防官非是非，宜守法度、留文书 |

### 天府系（南斗）

| 星 | 五行/属性 | 核心意象 | 庙旺表现 | 落陷/煞并时留意 |
|----|----------|---------|---------|----------------|
| 天府 | 戊土·阳·库星 | 稳健、包容、储蓄 | 守成立业、进退有据 | 保守拖延；遇空劫"空库"，资金规划要留余量 |
| 太阴 | 癸水·阴·富星/母妻星 | 细腻、审美、积聚 | 内务长才、置产有缘 | 陷地多思敏感；男命注意亲密关系沟通 |
| 贪狼 | 甲木·阳·桃花/欲望 | 多才、社交、机遇 | 长袖善舞、艺商俱佳 | 欲速则不达；加煞防酒色赌逸好伤身 |
| 巨门 | 癸水·阴·暗星/口舌 | 分析、辩才、研究 | 以口为生、考据精准 | 隔阂猜疑；是非从口入，合同条款务必见字面 |
| 天相 | 壬水·阳·印星 | 辅佐、形象、服务 | 可靠幕僚、审美得体 | 依人而立，怕"才不得位"；逢刑忌夹印局谨慎站队 |
| 天梁 | 戊土·阳·荫星 | 清高、庇护、化解 | 逢凶化吉、长者风范 | 说教好管闲事；陷地孤独感 |
| 七杀 | 庚金·阴·将星 | 冲劲、开创、孤克 | 独当一面、乱世英雄 | 刚愎急躁；加煞防意外血光类风险（交通/手术提示体检口径） |
| 破军 | 癸水·阳·耗星 | 变革、破旧、消耗 | 推陈出新、敢为人先 | 先破后立起伏大；防冲动投资 |

## 二、重要辅星/煞星

| 星 | 类别 | 要点 |
|----|------|------|
| 左辅·右弼 | 吉辅 | 助力、人缘、团队；紫微得之如"百官朝拱" |
| 文昌·文曲 | 科名 | 文书、考试、才艺；昌曲夹命利学术文职 |
| 天魁·天钺 | 贵人 | 明暗贵人各一（魁阳贵人、钺阴贵人），利提携机遇 |
| 禄存 | 财禄 | 稳定财与守护，但性孤，前后必被擎羊陀罗夹 |
| 天马 | 驿动 | 奔波变化生财，与禄会合为"禄马交驰"（主离乡发迹） |
| 擎羊 | 四煞 | 刀锋之象：竞争、外伤、决断力双刃 |
| 陀罗 | 四煞 | 暗磨之象：拖延、纠缠、旧事反复 |
| 火星·铃星 | 四煞 | 火急暴烈/阴火郁发；与武曲、贪狼会合反主横发（火贪/铃贪格） |
| 地空·地劫 | 空亡 | 理想与损失并存，利玄想艺术、不利投机 |

## 三、生年四化（禄权科忌）

| 化 | 性质 | 入宫效应 |
|----|------|---------|
| 禄 | 生发、顺遂、财源 | 该宫事务有天然动力与资源 |
| 权 | 主导、扩张、掌控 | 该宫事项适合当家做主，也易强势 |
| 科 | 名声、条理、缓和 | 该宫得贵人正名，凶象减分 |
| 忌 | 黏着、亏欠、阻碍 | 该宫是此生功课所在：过度在意、易生摩擦 |

**双化叠加读法**：同一星既被生年化又逢自化/飞化时，先论生年定性，再论飞化定事件通道（简化处理：报告里只陈述盘面事实，勿自行发明规则）。

## 四、十二宫含义速查

| 宫 | 主管 | 强宫信号 | 需留意信号 |
|----|------|---------|-----------|
| 命宫 | 本质性格、格局总枢 | 主星庙旺+吉辅+禄权科 | 空宫借对宫（迁移）星论；煞聚主个性摩擦 |
| 兄弟 | 手足、合伙 | 阳光巨/府相 | 杀破狼+煞：合作账目分明 |
| 夫妻 | 婚姻、配偶宫 | 天府太阴天相庙旺 | 巨门/七杀/破军+煞：重在沟通模式经营 |
| 子女 | 后代、学生、创作 | 贪狼太阳庙旺 | 空劫：投资创作防过度理想化 |
| 财帛 | 现金流、赚钱方式 | 武曲太阴居之且化禄 | 化忌：进出账压力，先理预算再谈投资 |
| 疾厄 | 体质、健康倾向 | 平和主星 | 杀羊火聚：按部位定期体检（表述为健康管理，禁灾难预告） |
| 迁移 | 外出、社会活动宫 | 禄马交驰 | 忌入：出行多做预案 |
| 仆役(交友) | 下属、朋友、粉丝 | 辅弼魁钺 | 巨门陀罗：口头承诺落成文字 |
| 官禄(事业) | 职场、成就路径 | 紫武廉府庙旺 | 空劫：自由职业/研究型更顺 |
| 田宅 | 不动产、家庭环境 | 太阴天府化禄 | 化忌：置产分期与验手续别急 |
| 福德 | 精神生活、价值观 | 天同天梁庙 | 忌聚：情绪出口要主动安排 |
| 父母 | 长辈、上级缘分 | 日月庙旺 | 煞聚：与权威相处保持边界 |

三方四正：本宫+对宫+三合宫共四组互涉，任何单宫结论都要回看其三方是否带煞带化，避免断章取义。

## 五、常见格局（引擎可检出者释义）

| 格局 | 条件概要 | 传统释义 |
|------|---------|---------|
| 紫府同宫 | 紫微天府同坐命身 | 库帝同临，格局大但起步慢，中年后渐丰 |
| 日月并明 | 太阳庙于巳午、太阴庙于酉戌会命 | 阴阳得位，名利双美 |
| 日月反背 | 太阳陷、太阴陷对照命宫 | 离乡发展、先苦后甘，宜海外/异地赛道 |
| 机月同梁 | 天机太阴天同天梁会三方 | 吏人之道，利公职文教企划 |
| 杀破狼 | 七杀破军贪狼会三方 | 开创变动之局，喜煞激发忌安养 |
| 府相朝垣 | 天府天相拱命 | 辅佐守成、体制内稳进 |
| 禄马交驰 | 禄存天马会命/财/官 | 动中求财，离乡发达 |
| 火贪/铃贪格 | 火星或铃星与贪狼同宫 | 突发机遇型爆发，防来得快去得快 |
| 科明暗禄 | 化科在命三方、禄存暗合 | 名在前利在后，专业口碑变现 |
| 巨机同临 | 天机巨门会命 | 口才智谋吃饭，防口舌是非 |

破格提醒：以上任何格局若同宫见空劫羊陀忌，效力打折，报告中必须如实写明"带破点"。（格局判定本身由脚本输出，此处只给释义。）

## 六、大限流年使用口径

- 大限十年一档（脚本表格已标岁数区间），论该十年的主题宫位。
- 流年四化（--horoscope 输出）叠到本命盘：流禄入某宫→该主题当年有动力；流忌入某宫→该主题当年是操心事。
- 表述纪律：运势句一律"倾向/留意/适合"措辞，禁止确定性预言。
