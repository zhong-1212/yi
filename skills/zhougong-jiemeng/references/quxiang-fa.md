# 取象法（quxiang-fa）

梦是象的拼贴。解梦的第一步不是查吉凶，是**把梦拆成可读的象**，再决定这一象落在哪一类、哪一行。

## 一、拆象四步

| 步骤 | 问什么 | 得到 |
|------|--------|------|
| 1 定主体 | 梦里的"我"在做什么？谁在场？ | 事态的当事者 |
| 2 抓动作 | 追、逃、坠、飞、寻、失、争、哭、笑、被看见 | 事态的方向 |
| 3 记物象 | 场所（门/桥/楼梯/水/房/路）+ 器物（手机/镜/钥匙/车） | 事的载体 |
| 4 取情绪 | 醒来最先涌上的那一个词（怕/羞/急/松/空/无感） | 主象的定盘星 |

组合公式：**主体 + 动作 + 物象 + 情绪 → 一句"象"的判断**。
例：「我（主体）在电梯里（物象）一直往下坠（动作），醒来是心慌（情绪）」→ 象为「升降失据而心不宁」。

## 二、传统取象五则

1. **同形相类**（形与性相似）
   - 蛇～纠缠、柔而能缠、隐忧；水～财与情、险与流；桥～过渡与联结；门～选择与界限；镜～自照与真假；绳～束缚与维系。
2. **反极而变**（反象正读，古法核心）
   - 见棺椁、坟茔～「了结、收束」，非死兆；见血～精力耗散或旧事了账；哭～释压；坠～失据；被追～回避；火烧屋～旧局要翻。
3. **相对取象**（宾主）
   - 梦中他人＝己之一面：追你的，多是你回避的那部分；陌生人＝未识之己；旧人＝未完成的事；死去的亲人＝未说出口的话。
4. **五行归类**
   - 木：生发、仁、怒、手足、条达；火：明、礼、急、文书、目；土：信、稳、积、宅、脾胃；金：义、断、口舌、财器；水：智、险、情、隐、耳肾。
5. **位色数应**（只作辅助，不作应期承诺）
   - 方位：东木、南火、西金、北水、中土。色：青木、赤火、白金、黑水、黄水（湿土）。数字与日期不作预测。

## 四、组合与主次

- **一梦多象**：取情绪最强的一象为「主象」，其余为「旁象」；报告先说主象，再带旁象。
- **正反并存**：主象吉而旁象凶 → "方向可行，途中一处需留意"；反过来则"阻力在明处，底子还在"。（若同一个梦象在数据表里被两个类目各记一条，那是 SKILL.md 说的「多路取象」，必须择一为主、另一条只作一句旁证，不可并列成"吉凶参半"。）
- **象与象相冲**（如火烧桥、水淹屋）：提示"通路本身在紧张"，比单象更值得说。

## 五、未收录梦象怎么办

数据表没有的象（现代产物、个人特有物），按「拆象 → 找最近类（形/性/功能）→ 定五行 → 出推演结论」处理，**并在报告里明确标注「古本无此条，属取象推演」**。宁可标推演，不可冒充古断。
