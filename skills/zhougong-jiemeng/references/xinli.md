# 心理层（xinli）

现代释梦是"理解自己"，不是"预知未来"。这一层不出吉凶，只出理解与可做的事。

## 一、三问定盘

1. 梦中最强的**情绪**是什么？（一个词，不是情节）
2. 这个情绪最近一次出现在现实里的哪件事上？
3. 梦里的"别人"，如果是你自己的一部分，是哪一部分？

三问答完，梦的骨架就出来了；古断与取象只是给这副骨架加语义。

## 二、常见母题速查

| 母题 | 常见心理义 | 先说这句 |
|------|-----------|---------|
| 被追 | 回避某件必须面对的事 | 看清"追你的"具体是什么 |
| 坠落 | 失控、失去支撑 | 最近哪块地盘让你没底 |
| 飞翔 | 掌控感、解脱 | 也可能是现实顺遂的投射 |
| 掉牙 / 脱发 | 形象失控、表达受阻、衰老焦虑 | 与"说出口/被看见"有关 |
| 裸体、找不到衣服 | 暴露恐惧、被评价 | 近期有无被审视的场合 |
| 考试、交卷、忘带笔 | 被评判、准备不足 | 常出现在新任务前 |
| 找不到门 / 迷路 | 方向感缺失、决策悬着 | 哪件事迟迟没定 |
| 水（清 / 浊 / 淹） | 情绪的量与清浊 | 浊水常伴情绪淤积 |
| 死去的旧人 | 一段关系的未完成 | 不是凶兆，是"该收尾" |
| 牙齿、头发（反复） | 压力身体化 | 先看睡眠，再看象义 |
| 被追赶而跑不动 | 行动受阻的无力感 | 现实里哪一步被卡住 |
| 裸奔 / 当众出丑 | 羞耻感、自我暴露 | 近期是否在"演给别人看" |

## 三、先排查近期变量（比象义更硬）

睡眠时长与质量、昼夜颠倒、酒精与咖啡因、药物、发热、经期与激素、近期重大事件（换工作、分手、搬家、考试、亲人健康）。

这些变量能解释相当一部分梦；报告里点了它们，结论会更稳，也避免把生理性乱梦说成"预兆"。

## 四、反复噩梦的轻量方法

1. **记录**：时间、情节、醒后情绪，各一两句，不追求文学性。
2. **找共同点**：同一场景 / 同一人 / 同一情绪 / 同一时间点。
3. **意象改写**：醒着时把结局改写成一个可控版本，默念一两分钟（意象重写思路）。
4. 若一周多次、白天功能受影响 → 建议寻求专业心理支持，语气平稳，不制造恐慌。

## 五、结束语口径

报告结尾用一句朴素的话收束，例如："梦是夜里的整理工作——它把你白天没来得及处理的情绪，摆成了画面。" 不要神秘化，不要暗示"有东西在提示你"。
