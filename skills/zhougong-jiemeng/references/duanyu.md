# 断语原则（duanyu）

三层材料（古断 / 取象 / 心理）落到报告时，按本文件约束尺度。

## 一、吉凶尺度

- 三档：**吉**（顺）、**中**（有阻可调）、**凶**（阻力明显）。数据表不设"大吉大凶"。
- 一律写成**趋势**，不写结局："多主…""宜…""须防…" 替代 "必然…""一定会…"。
- 同一象要能读出正反：古断里"若…则…"的分支就是提示——颜色、痛感、结局、是否认得人、天亮还是天黑，用户补一句细节，结论就可能翻转。**先问细节，再定正反。**

## 二、应期

- 只给"近日 / 近期 / 这一阵 / 等一个周期"，不给精确日期，不给数字。
- 用户追问"什么时候"：说明梦象不承担应期推算；若确实要择时，转 qimen-dunjia 或 meihua-yishu（另行起卦），不要在梦上硬凑日期。

## 三、重复梦

- 同一梦象反复出现：指向**未解决的心理议题**，不是"更准的预兆"。
- 处理：记录（时间/情节/情绪）→ 找共同触发点 → 做一次轻量行动 → 观察频率是否下降。

## 四、三层配比

| 层 | 占比 | 作用 |
|----|------|------|
| 古断（数据表） | ~40% | 给参照系，说明"古人怎么看这一类象" |
| 取象推演 | ~30% | 把用户这个具体梦落到象义 |
| 心理层 | ~30% | 情绪、近期压力、可执行的建议 |

收尾以**心理层的行动建议**为主，古断只作"另一个视角"。反过来（拿古断当结论、心理层当装饰）是错的。

## 五、禁忌（硬约束）

| 禁止 | 替换为 |
|------|--------|
| "此梦大凶，必败/必有灾祸" | "此象阻力偏重，宜先稳住基本盘，再谈推进" |
| "梦见死亡＝家里要出事" | "古法以'死'为事之终结，多指一段旧事收束、该收尾了" |
| 疾病诊断、脏腑断言 | 只给作息与体检提示；持续不适请就医 |
| "命定如此/天意不可违" | 禁止一切宿命化表达 |
| 精确日期、数字、彩票号码 | 一律不作 |
| 付费改运、法事、消灾、卖符 | 一律不提供、不推荐 |
| 恐吓性语言、死亡预言 | 改为风险提示 + 可做的事 |

## 六、高风险触发（要温柔，不要渲染）

出现以下情形：反复噩梦、梦中惊醒、长期情绪低落、梦中出现自伤或伤害他人的意象、因梦而持续恐惧——

1. 先说明：这是**压力与情绪的信号**，不是"凶兆"；
2. 给一两条能今天做的小事（记录、规律睡眠、和可信任的人说）；
3. 若已影响白天功能，建议寻求专业心理支持，把这句话放进报告，但不制造恐慌。

## 七、边界声明（每次报告结尾都带）

本技能是「象数 + 心理」的解释框架，不是预测工具，不承诺准确性；梦的价值在于把没来得及想的情绪用画面讲出来。
